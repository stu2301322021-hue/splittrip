# SplitTrip

SplitTrip е конзолно приложение за приятели, които организират
общо пътуване и споделят разходи.

## Проблем

Идеите, програмата и плащанията често са разпръснати между
чатове и таблици. Това затруднява планирането и проследяването
на сумите, които всеки участник дължи или трябва да получи.

## Планирани функционалности

- Създаване на пътуване.
- Добавяне на участници.
- Предлагане на активности.
- Гласуване за активности.
- Планиране и преглед на програма по дни.
- Записване и разделяне на общ разход.
- Преглед на балансите.
- Отбелязване на разплащане между участници.

## Технологии

- Python 3.10 или по-нова версия.
- SQLite за съхранение на данни - ще бъде добавено със ST-15.
- unittest за автоматизирани тестове.

Не са необходими външни Python библиотеки.

## Стартиране

От основната папка на проекта:

```bash
python app.py
```

При Windows може да се използва и `python app.py`.

## Тестове

```bash
python -m unittest discover -s tests -v
```

В началната версия още няма тестове; те ще се добавят
заедно със съответната реализация.

## Структура

- `app.py` — входна точка и конзолно меню.
- `splittrip/` — логика и съхранение на данните.
- `tests/` — автоматизирани тестове.

## Работен процес

Използваме Kanban: To Do → In Progress → In Review → Done.
Колоната In Progress има WIP лимит 1.

За всяка задача се създава бранч с ключа на Jira тикета.
Commit съобщенията и заглавията на Pull Requests съдържат
същия ключ. След първоначалния commit промените в main
влизат само чрез Pull Request.

Преди merge проверяваме промените, критериите за приемане
и приложимите тестове. След merge преместваме тикета в Done.

## Ограничения на прототипа

- Конзолен интерфейс без потребителски акаунти.
- Участниците се избират ръчно.
- Всички суми са в EUR.
- Разходите се разделят поравно между избраните участници.
- Приложението отчита разплащания, без да превежда пари.

## Текущо състояние
